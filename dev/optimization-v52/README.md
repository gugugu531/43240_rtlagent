# RAG cohort 52

This immutable screen contains ten locally revised card renderings, five per host.
Each case first proves that the reference passes and the target plus adjacent
error are detected by the same Vivado checker. Only then are one control and
one fixed-card repair call made with thinking enabled, equal sampling settings,
and no automatic retry. A failed case is retained and the queue continues.

The results test delivery, syntax and functional regression for the exact
rendering. They do not validate retrieval, automatic routing, or unseen-context
generalization. Runtime defaults remain unchanged.
