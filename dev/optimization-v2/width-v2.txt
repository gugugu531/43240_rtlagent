Use this method only for the expression implicated by the supplied failure. The public
task is authoritative; generic style preferences must not change its interface or timing.

1. Establish the expression's intended operation before checking its width. For a
   permutation or packing operation, map each destination boundary bit to its source;

2. Check the implicated operands' widths and signedness, the operation width, and the
   destination boundary. Distinguish sign extension, zero extension, truncation and
   wrapping only where the public contract requires them. Use one discriminating
   boundary example; do not repeatedly re-derive an already settled relation.
3. Apply the smallest correction. Preserve already compiling declarations, reset,
   priority and dependency modules unless evidence identifies them as faulty. An ANSI
   port is declared once in its header; do not add a second body declaration for it.
4. Verify the changed expression in the actual final file, then deliver that complete
