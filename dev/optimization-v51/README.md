# Local preparation and mechanical package v51

This package keeps the production RAG release and defaults unchanged. It
contains all 97 research cards, 24 narrow body revisions, 71 experimental
admission rules, five bounded source recognizers, 26 explicit tool-report
contracts, and 99 mechanical cases (97 cards plus two independent routed
development contexts).

The mechanical queue runs no generation model. Simulation discrimination and
synthesis/resource conditions are stored separately. Resource-only cards,
post-synthesis equivalence cards and unsupported source forms remain blocked or
partial even when their available tool checks pass. No result promotes a card
automatically.

The separate v52 frozen package screens ten revised renderings with equal
control/card repair calls. The remaining model plan in `experiment-plan.json`
is staged only; it is not executed by this mechanical queue.
