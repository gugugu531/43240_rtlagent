## 五张卡的改动

| 卡片 | 改动 |
| --- | --- |
| size-cast-sign | 原宽 signed 中间量，再赋给宽 signed 操作数；优先避免复制拼接；检查最负和负奇数 |
| division-rounding | 两个操作数先转成相同宽度 signed；公开非零除数域不另加 unsigned 分支；检查四种符号组合 |
| mixed-sign-arithmetic | 只检查当前表达式两侧操作数，保持数学关系和接口；明确停止条件 |
| weighted-partial-products | 无架构约束时允许直接乘法；需要部分积时只修缺失位权，不展开新架构 |
| conditional-X-merge | 明确已知选择器原样传递；未知选择器仅 0/0→0、1/1→1，其他包括 Z/Z→X |

五个修订后的真实示例均通过本地编译；size、division、X/Z 的三变体本地机械预检通过。修改只进入独立夜间资产，原 32 张库、研究 v2 发布锁与旧实验不改。

X/Z 草案的旧备注曾要求检索发布前重编码；本夜明确改为固定卡片实验，用本夜清单绑定新版本／渲染哈希，不读取旧 dense 索引。将来接回 ranked retrieval 必须先重新编码变化的文档投影，不能用原向量冒充新版本。
