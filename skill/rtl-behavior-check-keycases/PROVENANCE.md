# 来源与许可

本技能由本项目编写，不是从上游技能目录复制的文件。它采用公开验证实践中的常见做法：

- 明确时钟、复位或初始化过程、输入激励和采样时刻；
- 自动比较实际输出与期望输出，并记录不一致，不只依赖人工查看波形；
- 选择少量能够区分常见错误的场景，明确有限输入表未覆盖的行为。

这些做法属于通用验证方法，不据此主张原创验证理论，也不说明少量场景优于完整验证。相关研究的借鉴范围见[报告](../../REPORT.md)。本项目编写了包含输入、期望值和逐点简短解释的行式检查表规范。技能正文以 `self-checking testbench` 描述这类方法。在本实现中，框架按激励与采样计划生成测试台，由 XSim 输出采样值，再由 Python 按测试点比较实测值与期望值。

本技能正文不包含 VerilogEval 测试台、参考模块、官方题库答案或其他第三方原文。此说明仅针对本技能；仓库中其他技能的开源来源与复用范围见[技能包说明](../README.md#现有技能与来源)。

本技能采用 MIT 许可证，版权声明保留在 `skill.md` 文件头，许可全文见[仓库许可证](../../LICENSE)。`review_status: frozen_candidate_not_default` 表示它不参与求解技能的自动选择；当前 `guided_verify` 的独立检查角色在建表、修正自身回复格式和按点复核时固定使用该方法。这一使用方式不代表已经证明检查器正确或提高了模型成绩。
