# failures/

失败原因分析，是 `REPORT.md` 中失败分析的素材（失败分析是工程质量评分的重点）。

一类问题一个文件，例如 `reset-polarity.md`、`port-width-mismatch.md`。每个文件写清楚：

- 现象：哪些题、判定到哪一级（L0 未通过 / L1 可编译 / L2 仿真通过）、出现的频率
- 证据：`../runs/<运行编号>/...` 下相关 trace（工具调用记录）和日志的路径
- 原因：为什么会出错
- 尝试过的办法：改了什么、效果如何、没用的话为什么没用

**这里可以引用参考答案，但这类内容绝对不能复制到 `skill/` 或 `agent/` 中**
（`SCORING.md` 第 2.9 条：预置答案会导致该赛道成绩作废）。技能包里只写适用于同类
问题的通用规律。
