# failures/

失败样本归因，`REPORT.md` 失败分析（工程质量项的评定重点）的素材。

一类问题一个文件，例如 `reset-polarity.md`、`port-width-mismatch.md`，每个文件写清：

- 现象：哪些题、落在哪一级（L0/L1/L2）、出现频率
- 证据：`../runs/<运行 ID>/...` 下的 trace 与日志路径
- 归因：为什么会错
- 尝试：改过什么、效果如何、为什么无效

**这里可以引用参考实现，但这类内容绝不能复制进 `skill/` 或 `agent/`**
（SCORING 2.9：预置答案，track 成绩作废）。技能里只写可泛化的规律。
