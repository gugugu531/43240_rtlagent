# 实验指标与比较范围

本说明于 2026-10-14 整理，用来阅读[实验记录](../experiments/index.md)，不改写各次原始结果。正式评分以仓库根目录的 [SCORING.md](../../../../SCORING.md) 为准。

## 先确认数字的含义

| 指标 | 阅读方式 |
| --- | --- |
| 等级系数平均值、题集得分 | 各题等级对应系数的平均值；不是 L3 通过率 |
| L3 比例 | L3 样本数除以同口径计分样本数；应同时列出分子、分母和环境失败 |
| 旧表的 pass@1 | 部分历史工具用此标题表示等级加权得分，须看对应脚本与等级分布，不能直接当成功率 |
| 旧表的 pass@5 | 先确认是否每题实际有五次独立采样；只有一次采样、或表中与 pass@1 相同，不能据此声称测得五次采样效果 |
| 资源占用与速度 | 区分单请求与并发吞吐、分配显存与整卡显存、观察峰值与运行全程峰值 |
| mock 结果 | 假模型只检查流程和产物，不说明模型能力或功能正确率 |
| 占位满分线 M | 旧实验用 M=2.5 换算的增益分只适用于当时示例参数，不是正式赛事得分 |

环境错误、超时、模型请求失败和 RTL 判定不通过分开说明。未知 token 不记成零；被截断的输出与完整输出分开比较。

## 题集不能混用分母

历史实验中的 155 题由当时选用的 152 道 VerilogEval 题和 3 道示例组成，不等于现在来源目录中的全部题。
34 题筛选、155 题复测与目前 258 题全池、241 题合格候选、60 题均衡开发集也不相同。
重现时查运行清单、配置和排除项，不能只看文件名中的 full、quick 或 balanced。
当前题库组织见[题集说明](datasets.md)，筛选数字的来源见[题集验收](../notes/2026-10-14-balanced-datasets-validation.md)。

## 比较模型和修复收益

先对齐模型权重与 revision、量化、服务版本、思考开关、提示词、代码提取、输出额度、单题预算、题集和采样数。
不同 GPU 或并发数的耗时不能直接解释为模型速度差；AutoDL 测量也不能直接证明 AMD 目标环境可运行。

旧 baseline 与 Agent 最终结果之差同时包含请求、提取和修复策略的影响，不能直接归因于某一次修复。
证明修复收益应比较相同初始候选和预算下的对照，保存逐样本变化与检查点证据。
当前初始检查点重放能力见[运行契约](agent-runtime.md)；它不等于所有历史 trace 都能重放。
