# 生成参数诊断之后：先做 E1，再做 E2

类型：实验建议，不是已执行结果。日期：2026-10-13。
范围：本轮只恢复已授权的 11 题诊断；以下新增模型实验待确认，不自动启动。

## 推荐顺序

生成参数诊断收尾 → 冻结生成设置 → E1 的精简三组 → E2 的两候选对照 → quick-34 验收。
知识卡片的离线验收可在前两步同时准备，不必等到 E2 后；检索增强生成（RAG）的效果测试
作为 E1 的一组，而不是与 E1 二选一。

11 题按历史表现选择，每组只有一次生成，不能当独立泛化验证。若生成参数改善幅度不稳定，
先对预先指定题集与 seed 做少量重复；网关目前 seed 固定，需要显式实现/审计 seed 参数，
不能把 samples=3 当作三个独立 seed。选用某配方只作为后续开发基准，不直接修改正式默认。

## E1 先收窄为三组

| 组 | 行为 | 回答的问题 |
| --- | --- | --- |
| A0 | 与方案 A 相同首次提示和提取，只保留首次候选，不修复 | 没有修复时能做多少 |
| A1 | 相同首次生成，合规检查失败后给结构化反馈，最多一次修复 | 工具反馈修复是否值得 |
| A2 | A1 + 由自身错误证据检索的 1～2 张短卡片 | 在相同修复机制上，检索额外有无收益 |

先比较 A1−A0，再比较 A2−A1；后者才是这轮 RAG 的增量效果。官方 baseline 继续作为外部参照，
但它与 Agent 的首次提示不同，不能代替 A0 来隔离修复本身。完整日志、仅错误码、历史 repair_loop
等其他反馈格式稍后按必要性追加，不与第一轮的候选数、审查和规划一同变化。

建议分两层验证：

1. **受控修复小实验**：同一个首次候选、同一份自身工具证据、相同剩余预算，比较 A1/A2；
   初始候选不能根据隐藏判定筛选。保存首次生成的参数、原文、提取代码、哈希和成本。
   重放不重新调用模型生成首份答案；总成本计入首份生成的时间和 tokens。
2. **端到端确认**：用冻结的模型、提示、采样和预算跑三组完整流程，报告随机性与真实成本；
   不把离线重放速度当成部署速度。

固定 360 秒单题预算、输出预留和请求上限；A1/A2 的修复次数、失败策略、选择策略相同。
**目前 8192 是单次请求输出上限，不是整题累计 token 上限。** 若报告“相同累计 token 预算”，
必须先实现跨调用计数、剩余额度分配和缺失 usage 的保守处理；此前只能准确写成
“相同墙钟与单次输出上限，并报告实际累计消耗”。不能用取消整轮时限来取消这些解题预算。

## 知识卡片先验收什么

现状：15 张草稿卡片，检索/结构与来源测试已做，尚未做独立 HDL 执行验证或接入正式 Agent。
不立即上向量数据库、扩大 Ross 全库或下载 embedding 模型。

- 用不来自赛事题目的独立小例子核对建议，包含应当命中、未知错误、工具/版本不符和不应修改的情况。
- 冻结资料版本、来源和哈希；测量检索命中率、错用率、漏检与预算省略，不只看能否返回文字。
- 错误检索只用自身工具、版本和错误命名空间，不以题号或隐藏 judge 作为查询/触发条件。
- 按实际 tokenizer 控制注入；保留题面、接口和当前完整候选，压缩或省略卡片，不裁剪关键 RTL。
- 记录卡片 ID、命中理由、实际注入文本、哈希、token/延迟、无命中与错误；无命中走 A1 原流程。
- 先采用独立可替换的检索/反馈节点；正式代码不能导入 dev，资料迁入提交区前单独审核许可证和污染。

当前工具错误中存在草稿卡片没有覆盖的错误码；不要用模糊匹配伪装准确命中。
若整体没有改善，需区分“没有触发/命中”和“命中后建议无效”，不能直接宣布 RAG 无用。

## 为什么 E2 稍后

E2 比较“一候选修复”与“两候选确定性选择”，需要稳定的生成参数、反馈和成本记录。
在这些还变化时同时开启分支搜索，无法区分收益来自随机采样、反馈还是检索。
首轮只做宽度 2，并按同一累计 token/时间上限比较；同等自身证据保留早期候选，
不使用隐藏 TB 选答案，也不把两倍预算的提升当成搜索策略收益。

最后用 quick-34 做回归检查；它已被反复分析，不能称为未见验证集。需要泛化结论时，
另预留尚未用于调参的公开任务，事先冻结选择清单。

## 功能错误要另开一组

编译/综合通过，不代表功能正确。当前推荐采样组已评分的 `Prob105_rotate100` 和
`Prob138_2012_q2fsm` 为 L1，但自身编译/综合证据没有失败；这是开发分析，不允许反馈给求解器。
只在编译错误时检索修复卡片，不会自动解决这类问题。

若要测设计卡片，用题面触发的简短规格检查单另开实验，例如复位、优先级、移位语义、
FSM 输出时机；不要与 A2 同时新增模型审查或自建 TB，再把变化归因于错误检索。
自建检查也不是官方判定真值。正式流程始终禁止读取隐藏 TB、参考答案和 judge 成绩。

每组至少记录：L0/L1/L2/L3、均值、修好/修坏、首份与最终代码哈希、实际模型调用与
输入/输出 tokens、墙钟 p50/p90、卡片覆盖、超时/模型/环境失败；保留低分和失败样本。
