Agent 日志查看器

在本机查看执行过程与完整响应

支持整个实验目录、单题输出目录，或单独的 trace.jsonl。文件只在本机读取。

执行流程

导入后，在这里查看实际执行顺序。

如何导入日志

选择包含 trace.jsonl 与 records/ 的输出目录，可看到请求、回复、候选代码和工具日志。也可选择整个实验目录，再切换样本。

单独打开 trace 只能查看事件中已有的信息。详细记录在外部目录时，可再次选择该目录补充导入。拖入文件夹或多个文件也可以。

连接顺序表示实际执行记录，不推测未执行的分支。只有开始记录的调用显示“未见结束”，不认定仍在运行。重新选择目录可刷新文件。

节点详情

从一次运行开始

点击“选择日志目录”，选择 Agent 的单题输出或实验目录。

点击左侧节点，查看输入、输出、模型回复和错误详情。

不需要启动服务器，也不会上传日志。
