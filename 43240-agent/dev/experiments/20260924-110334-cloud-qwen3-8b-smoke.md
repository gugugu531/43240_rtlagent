## 结论

链路可用。分数只有 8 题、1 次采样，不能用来比较。

主要问题是**超时**，不是模型写错：
- agent 3 个 L0 都是 180 秒时模型请求超时（`LLM_TIMEOUT_S` 默认 180），被记为 agent 异常
- baseline 4 个 L0 是 300 秒请求超时（`baseline.py` 的 `TIMEOUT_S`，不可修改）
- 原因是 Qwen3-8B 默认开启思考，输出很长；8 路并发下单路生成速度较慢

下一步要弄清：单路生成速度、思考长度分布、并发数对超时的影响。评测时赛事方逐题投递，
单路速度才是关键；自测时应降低并发，或至少把并发数记进实验记录。
baseline 另有 2 个语法错误（L0），需要看输出里是否混入了思考内容。
