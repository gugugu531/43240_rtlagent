### 建议一：首选 A6 `Qwen3-4B-Instruct-2507`（BF16）

理由按重要性排序：

1. **可计算分最高且是实测的**：`S_b` 0.371 + `S_a` 0.518 → 增益 1.397 → 可计算分 **30.1/70**，
   是目前唯一同时有全题集 `S_b` 与联合 `S_a` 且分数领先的候选（见「联合跑分」一节）。
2. **对 agent 改进最友好**：它的分母最低，同样的 `S_a` 提升换来的增益最大。
   换句话说，**方案越做越好，选它越划算**（建议二里的交叉表说明了这一点）。
3. **风险最小**：BF16 权重只有 7.67 GiB，**没有量化格式风险**（不用管 AWQ 内核、fp16 激活、
   gfx1201 上的算子兼容）；32 GiB 单卡余量最大。
4. **已验证过速度**：并发 1 约 52 token/秒，比对照 A7（30.0）快，够 agent 跑多轮。

### 建议二：唯一值得花一次实验去验证的挑战者是 A1 `Qwen3.6-35B-A3B`（AWQ-4bit）

不是因为它现在更好，而是因为它**离得很近、而未知量只有一个**。定量看：

| A6 实际能到 | A1 需要到 | A1 需要的优势 |
| ---: | ---: | ---: |
| 0.50 | 0.71 | +0.21 |
| 0.55 | 0.78 | +0.23 |
| 0.60 | 0.84 | +0.24 |
| 0.65 | 0.90 | +0.25 |
| ≥0.70 | — | **A1 已经不可能反超** |

（M 取 2.5，`可计算分 = 30·S_a + 40·min(1, ln(增益)/ln M)`；增益 = `S_a / S_b`，
A1 的 `S_b` = 0.610、A6 的 `S_b` = 0.371。）

**为什么这个差距值得测**：同一套 agent 下，中大型 MoE 的 `S_a` 确实比 4B 高 0.18
（A5 0.700 对 A6 0.518）。也就是说 A1 需要的 +0.21 到 +0.26 **正好落在已知差距附近**——
测一次就知道，不测就只能猜。这是当前性价比最高的一次实验。

| 情形 | A6 可计算分 | A1 可计算分 | 谁高 |
| --- | ---: | ---: | --- |
| A6 0.518（实测） 对 A1 0.70 | 30.2 | 27.0 | A6 |
| A6 0.518 对 A1 0.80 | 30.2 | 35.8 | A1 |
| A6 0.60 对 A1 0.75 | 39.0 | 31.5 | A6 |
| A6 0.60 对 A1 0.85 | 39.0 | 40.0 | A1 |
| A6 0.65 对 A1 0.85 | 44.0 | 40.0 | A6 |
| A6 0.70 对 A1 0.90 | 48.8 | 44.0 | A6 |

注意最后两行：**如果 agent 把 A6 也抬到 0.65 以上，A1 就再也追不上了**。
所以这个建议有一个明确的前提——`S_a` 的提升主要由「模型能力」决定，而不是由 agent 决定。

### 建议四：需要团队拍板的两条口径

1. **`M`（满分线倍数）未知**：M 越小越有利于低基线方案。A5 反超 A6 需要 M > 3.48；
   若 M 落在 2–3（`SCORING.md` 示例是 2.5），建议一成立。
2. **决赛硬件未验证**：A1/A2 在 32 GiB 上要用约 90% 显存，且**MoE 在 gfx1201 上无人验证**；
   A6 的 BF16 只有 7.67 GiB，这两条风险都小。如果验证窗口拿不到 R9700 实例，
   这条风险本身就应该计入选择（偏向 A6）。

## 目前的倾向

> 这一节写于第一批之后。**第二批（A1/A2）加入后，中基线档多了一个「快十倍」的选项**，
> 所以下面「倾向小模型」的结论要连同第二批一起看：A6 与 A1/A2 现在是两条不同的路，
> 谁更好取决于 agent 能把各自的 `S_a` 抬到多高。

**排序的依据变了。** 第一轮数据显示：六个候选如果只把「可修的三类 L0」修好，
`S_a` 的上限都落在 **0.67–0.73** 这个窄区间里（见 `../failures/sim-mismatch.md` 的上限表），
而它们的 `S_b` 相差近一倍。也就是说——

- **基线低的小模型增益高得多**：Q1a 上限 2.07 倍、A6 1.75 倍、Q1b 1.71 倍；
  而 A5 只有 1.24 倍、A7 1.10 倍、A4 1.19 倍。
- 能力项的差距则相反：A7/A5 的 `S_a` 上限（0.729/0.730）略高于 A6（0.690）、Q1a（0.711）。
- 代入 `30·S_a + 40·min(1, ln(增益)/ln M)`（M = 2.5，用上限值粗算）：
  **Q1a ≈ 53 分、A6 ≈ 45 分**，明显高于 A5 ≈ 31 分、A7 ≈ 26 分、A4 ≈ 28 分。

所以**初步倾向从「中大型 MoE」移向「小模型 + 强 agent」**。但这条推论依赖一个未经检验的
假设：agent 真能把那 27%–37% 的可修 L0 兑现成 L3。**联合跑分就是去检验它。**

同时保留一个反向的考虑：小模型的可修错因多，也可能只是「语法都写不对」，
修完仍大面积失配，那时它的 `S_a` 会卡在 0.5 上下，反而输给 A5/A7。
`../failures/sim-mismatch.md` 里按题型的表已经露出苗头：4B 在
「移位寄存器/LFSR/元胞自动机」上通过率是 0.00–0.10，而 A5/A7 是 0.70–0.80。

**入围联合阶段的四个**（按上限与能力综合，差距不大，都值得测）：

| 入围 | 理由 |
| --- | --- |
| A6 `Qwen3-4B-Instruct-2507` BF16 | 上限 1.75 倍、**速度最快的合规配置之一**、BF16 无量化风险 |
| Q1a 同 A6 的 AWQ-4bit | 上限最高（2.07 倍），用来检验「4-bit 掉分但是否提高增益」 |
| A5 `Qwen3-30B-A3B-Instruct-2507` AWQ-4bit | 能力上限最高、MoE 速度快，作为「中大型」代表 |
| A7 `CodeV-R1-RL-Qwen-7B` BF16 | 对照组：验证「一次性裸跑强 → 增益小」这条判断 |

A4 与 Q1b 作为备选，时间允许再补。

## 2026-09-25 联合跑分：第一次拿到 `S_a`

用冻结的探针 `probe-v0` 跑 `--modes agent,baseline --taskset quick`（分子分母同一次运行）。
完整逐题分析见 `../notes/2026-09-25-joint-first-results.md`。

| 候选 | `S_b` | `S_a` | 增益 | 能力分 | 增益分 | 可计算分 / 70 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A6 `Qwen3-4B-Instruct-2507` BF16 | 0.371 | 0.518 | **1.397** | 15.5 | **14.6** | **30.1** |
| A5 `Qwen3-30B-A3B-Instruct-2507` AWQ-4bit | 0.594 | 0.700 | 1.178 | **21.0** | 7.2 | 28.2 |
| A7 `CodeV-R1-RL-Qwen-7B` BF16（对照） | **0.718** | **0.765** | 1.066 | 22.9 | 2.8 | 25.7 |
| Q1a `Qwen3-4B-Instruct-2507` AWQ-4bit | 0.412 | 0.471 | 1.143 | 14.1 | 5.8 | 20.0 |

**结论**

1. **按现有数据，A6 是更稳的选择。** A6 靠「低基线 + 高增益」、A5 靠「高能力分」，
   两者在 `M` 上的交叉点是 **M ≈ 3.48**：M 取 2.0 / 2.5 / 3.0 时 A6 分别是
   34.8 / 30.1 / 27.7，A5 分别是 30.5 / 28.2 / 27.0，**A6 全胜**；只有 M > 3.5 才反超。
   `SCORING.md` 第 4.3 节的示例用 2.5，所以不再把「等 M」当作不定的理由。
2. **但还不算定案**，因为这两个数只来自 `quick` 34 题的单次采样（绝对值会比全题集高
   0.06–0.08），而且 A6 的绝对能力低（`S_a` 0.518 对 0.700）。**待办是全题集复跑两者**，
   复跑之后若排序不变即可定案。
2. **对照组假设成立**：RTL 专用模型 A7 的 `S_b` 与 `S_a` 都最高，增益却最低。
3. **4-bit 伤的是修复能力而不是生成能力**：Q1a 的基线（0.412）高于 A6（0.371），
   但加上 agent 之后被 A6 反超（0.471 对 0.518）。与全题集上的量化对照一起看，
   倾向是「显存允许时优先 BF16 / 8-bit」。
4. **真正的瓶颈是 agent 而不是模型**：四个候选的 `S_a` 都停在 0.47–0.77，
   且每个都把 2–3 道基线做对的题改坏（每轮重写整份文件）。
   把 `S_a` 往上推要靠「局部修改 + 功能自验证」，换更强的模型会同时抬高分母。

**下一步（按收益排序）**

1. 改 agent：把「每轮重写整份文件」改成在上一版上局部修改——不需要换模型，直接少丢 2–3 道题。
2. 加功能自验证（差分仿真投票等），把 L1 往 L2/L3 推——增益的主要来源。
3. 前两名在全题集上复跑，确认排序（目前只有 `quick` 34 题的单次采样）。
4. `M` 公布后再按可计算分定模型。

## 2026-09-24 的倾向（已被上面一节取代，保留备查）

- 首选候选：Qwen3-30B-A3B-GPTQ-Int4（关思考）——基线适中、速度最快
- 对照候选：Qwen3-8B（关思考）——基线最低，但模型能力可能限制上限
- 32B AWQ 模型暂不考虑：基线高、速度慢、显存超限
