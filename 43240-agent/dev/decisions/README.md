# decisions/

重要决策记录：需要长期查阅、会影响方案设计的决定，比如选哪个模型、用哪个推理后端、
重试策略怎么定、用什么量化方式。日常过程记录放 `../notes/`，不放这里。

文件名：`<四位编号>-<主题>.md`，编号依次递增，例如 `0002-model-choice.md`。

每篇包含：

| 部分 | 内容 |
| --- | --- |
| 开头的表格 | 状态（待定 / 已决定 / 已作废）、记录日期、相关文件 |
| 背景 | 为什么要做这个决定 |
| 可选方案 | 考虑过哪些方案，各自的优缺点 |
| 结论 | 选了什么、为什么；有实验数据的附上 `../experiments/` 中的运行编号 |
| 影响 | 需要同步修改哪些文件 |

决定被推翻时，不要删除原文：把状态改为「已作废」，并写明被哪一篇取代。

写 `../../REPORT.md` 第 2～4 节（模型选择、推理栈、智能体设计）时，素材从这里取。
